# 离线演示与恢复检查

使用独立数据目录启动合成研究服务，再打开本机 8766 端口。

```bash
BINANCE_AGENT_DATA_DIR=/tmp/binance-agent-demo uv run --frozen python -m binance_agent.research_demo
```

| 操作 | 预期结果 |
| --- | --- |
| 市场研报选择 BTCUSDT，生成研报 | 无需问题，展示结论、条件、风险和依据 |
| 指定话题关联 ETHUSDT，询问 ETF 是否获批 | 原文区分申请与批准，可阅读已保存引用 |
| 指定话题不关联币种，询问监管提案 | 独立专题、无交易价位，不请求 Binance 行情 |
| 关联 SOLUSDT，核查攻击报道原文 | 缺失正文，保留缺口或证据不足结果 |
| 运行中提交补充 | 显示已接收，再显示已纳入；最终报告使用最新输入版本 |
| 完成后追问，再选择前一轮 | 新轮更新、旧结果不变，复制与保存仍指向所选版本 |
| 活动运行期间退出后重开 | 历史显示中断，由用户恢复；原预算与期限不重置 |

行情、正文与模型响应均为合成内容。该演示验证交互和故障行为，不能证明模型质量、收益、真实费用或多 Agent 优势。完整打包与原生验收见[打包说明](../packaging.md)。
