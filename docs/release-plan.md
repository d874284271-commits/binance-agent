# Binance Agent 双平台开源预览版实施计划

本计划是当前产品与发布权威记录。用户于 2026-11-14 明确授权完整实施、候选提交、双平台构建、私有仓库 draft 准备及验收后的同步公开发布。候选状态与实际验收范围见[版本说明](releases/v0.3.0a1.md)。本文件的目标不代表已实现或已验收。

## 目标与范围

版本 `0.3.0a1`：Windows x64 ZIP、macOS Apple Silicon arm64 `.app` 分发包与同一版本源码同步发布，GitHub Release 为 prerelease。采用未签名预览版，发行者签名及 macOS 公证留待正式发行。本决定替换旧计划的“专题必须关联币种”和“首发必须正式签名”。

沿用 Python、FastAPI、LangGraph、pywebview、HTML/CSS/JS。保留研究、证据核验、风控、预算、恢复；不增加交易执行、自动盯盘、云端账号、自动更新器或前端框架。保留工作区全部既有成果，按公开清单整合，不清理整个工作区。

| 入口 | 输入 | 结果 |
| --- | --- | --- |
| 市场研报（默认） | 币种、市场；无需问题 | 综合研报、条件性建议、依据、风险、重新评估条件 |
| 关联币种专题 | 问题、关联资产 | 优先回答问题，说明对资产的影响 |
| 独立专题 | 问题；无需币种或市场 | 行业、监管、宏观研究；无占位交易对或交易价位 |

## 产品与界面契约

主导航“研报 / 历史 / 设置”；研报内切换“市场研报 / 指定话题”。深色、黄色强调、系统字体，默认窗口 1040×760，兼容 440×680，正文约 14px，关键操作和结论不靠缩字适配。

首次提供“连接模型”和标注合成内容的“查看示例研报”，示例不联网、不消耗模型额度。模型连接只要求服务、密钥、模型，兼容既有供应商和自定义服务；分角色模型与结构化输出进入高级设置。保存后恢复研究草稿。搜索可选，资料不足如实显示范围和缺口。保留代理、数据源、时间窗、桌面偏好；请求、超时、并发采用默认值并收进高级设置。热键、置顶默认关闭，热键失败不影响普通窗口。

市场研报沿用最近资产时一键启动。专题默认独立，通过“关联币种”增加范围；独立模式隐藏市场选择。币种候选包含代码、名称和最近选择，提交前展示实际交易对及市场；空值、无效币种、空专题问题就地提示。两入口保留各自草稿，切换不启动研究，不把专题问题带入市场研报。

结果顺序：直接结论 → 建议与改变判断的条件 → 主要依据（详细过程折叠）→ 来源与缺口。市场保留经过风控的方向、入场、止损、目标；观察/不行动不显示虚构价位。专题不强制套交易模板。

| 操作 | 会话与轮次语义 |
| --- | --- |
| 生成新研报 / 新建话题 | 新会话，隔离原上下文 |
| 更新当前研报 / 话题 | 原目标，新轮次，刷新资料 |
| 继续追问 | 原会话，新问题、新轮次 |
| 运行中补充 | 当前轮输入版本递增，区分已接收/已纳入 |
| 恢复中断 | 原轮次、原预算、原截止时间 |

结果自动存历史；复制与 Markdown 保存读取当前选定的已保存版本，不调用模型。专题重开保留标题、范围、轮次；回看旧版不被实时结果覆盖。原生保存取消不报错、不写文件。

移除正式 UI 的 Trace、Planner、Deep 预检、评估校准、原始 JSON、checkpoint、Agent 驻留、伪提醒，并删除对应 DOM、请求、事件和失效样式。保留脱敏日志、错误原因、证据原文阅读、内部存储及恢复。正式应用移除无产品调用者的评估、校准、观察探测、调试回放路由；实验与评估保留源码开发者路径。

## 共享实现契约

会话创建接收 `mode: report | topic` 和 `target: {kind: asset, symbol, market} | {kind: independent}`，保存原始目标；轮次保存本轮问题、动作、输入版本和结果。report 必须 asset；topic 可 independent。改变意图或对象新建会话，不能仅按同交易对复用。轮次区分首次、更新、追问。request_id 去重涵盖意图、范围、问题及动作。旧客户端保留原契约，旧记录标“历史研究”，不猜测分类。

市场路径沿用行情预检、分析师、取证、辩论、风控、策略合成，不加研报改写 Agent。专题复用任务拆解、正文读取、研究者、核验者、主管：问题提取检索目标与时间条件 → 发现资料 → 读取/核验 → 专题结论。明确的资料日期范围覆盖默认最近时间窗，首尾日期均包含；未知发布时间保留并交由正文核验，不能冒称已确认时间。局部任务缺口与分歧进入最终核验且阻止误标完整。关联专题可用行情上下文；独立专题不调用行情、资金费率或策略节点，Binance 不通不阻断。

资料上下文支持问题与可选资产。独立专题只调度支持问题或公共资料的来源，跳过必须交易对的提供方。默认公共资讯、官方 RSS 和支持问题查询的来源；可选 Tavily 通过现有 HTTP，关闭生成答案及正文返回，正文走现有抓取核验。搜索凭证进现有密钥存储，只展示连接状态。无密钥/搜索失败仍处理已有资料，无足够材料交付证据不足，不用模型记忆冒充证据。

默认每轮 100 次请求、600 秒及现有文档上限；所有新增模型与搜索调用进入原轮预算，不另起后台系统，恢复不重置。

统一报告包含类型、标题、范围、时点、摘要、依据、来源、缺口、完整性。市场继续保留 StrategyAdvice / advice 字段；专题无伪 trade/no_trade，也无需交易建议才能完成。SSE、摘要、历史上下文、完成事务、恢复支持两类结果。完整性为 complete / partial / insufficient_evidence，与失败/中断分离。所有结论经过核验；旧输入版本不得发布。

SQLite 版本迁移在事务中增加研究范围与报告存储，独立范围允许 NULL 交易对。迁移前备份，失败回滚，不清库。保留会话/轮次/证据关联，旧已完成记录可读；不兼容的旧中断轮次明确引导重新研究。

新增只读真实币种目录（按市场，复用行情客户端缓存限流）、只读报告与 Markdown 导出；显示、复制、保存使用同一结果来源。保持 loopback/Origin、跨来源密钥保护、安全文本渲染和幂等。

## 依赖、源码与发行

RSS 改为核实的 feedparser 6.0.14 + feedparser-sgmllib 2.1.0，RSS/多源解析回归，最终包不含旧 sgmllib3k，收集实际许可正文。统一锁、构建环境、包内 PyObjC；应用、关于页、平台资源、包名、Release 统一版本。保留 MIT，第三方依赖与真实网页资料分别核查分发依据。

检查拟公开文件与分支/tag 可达历史，排除密钥、运行时配置、用户记录、个人工具缓存、无权再分发原文。更新 README、PRODUCT、DESIGN、packaging、CHANGELOG，补 CONTRIBUTING、SECURITY、问题模板。README 优先下载、首次配置、一键研报、专题、新截图；工程细节进开发者文档。不宣传无实验证据的准确率/盈利/多 Agent 优势。

CI 同提交分别构建 Windows x64 ZIP 与 macOS arm64 包并汇总，普通 push/tag 不直接发布残缺 Release。原仓库保留为 binance-agent-private-history，保持私有并保留全部分支和 PR；用户于 2026-11-14 确认这一安排，因为旧 PR 中包含不应公开的私人实验记录。以公开清单创建无旧历史的 binance-agent 私有发布仓库，先准备完整 draft（源码版本、两平台包、许可、SHA-256、说明），验收后公开干净仓库并发布 prerelease。说明未签名/未公证限制，不要求关闭全局防护；只列实际验证系统，不宣称 Intel Mac、Windows ARM 或未测范围。

## 验收与停止条件

- 首次使用不读开发文档能连接模型/看合成示例；高级参数非必填。
- 一键市场研报无需问题，完成首屏能找到结论、依据、风险。
- 关联专题回答问题并标关联资产；独立专题无交易对、无行情请求、无占位策略，Binance 不通仍可完成。
- 无搜索密钥公共来源仍可用，搜索失败保留证据，不足准确降级。
- 新建/更新/追问与标签一致，切入口无污染；补充状态可辨、无旧版本发布；重连不重复启动，恢复原预算。
- 新旧历史可读、专题标题/范围恢复；迁移失败保留数据。
- 导出当前版本、时点/风险/来源齐备，无日志密钥和额外模型调用；原生取消无写入。
- 安全文本、跨来源密钥保护、键盘可用，1040×760 与 440×680 无横向溢出。
- 两平台实际完成设置、三入口、历史、保存、停止、关闭/重开，退出后后端结束。
- 干净 checkout 安装/测试通过，两包与源码一致，许可与公开内容审查闭合。

使用现有定向测试，新增独立专题、隔离、迁移、导出的必要行为测试。冻结后运行完整 Ruff、格式、mypy、JS 检查、pytest，浏览器与原生覆盖主流程。真实模型只做明确额度的小量 smoke；合成演示仅作交互/故障证据。证据核验、数据保护、原生验收或许可仍有阻断时保持 draft，不提前宣称发布完成。
