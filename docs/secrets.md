# 模型与搜索密钥

在“设置 → 模型连接”填写模型服务的密钥，保存后返回研究；已有连接留空会保留密钥。Tavily 和其他需要认证的数据源在“资料与搜索”中配置。**应用不需要 Binance API Key**，只访问公开行情。

配置文件只保存密钥引用名，界面只显示是否已连接。运行时按顺序读取：环境变量或 `.env`、本地 Fernet 加密库、系统 keyring。加密库通常位于 `~/.binance_agent/secrets.enc`，加密密钥由系统钥匙串管理；源码位置为 `infra/secrets.py`。

模型与搜索请求会将研究输入发到配置的服务。请使用自己的有效凭证与可信的服务地址。更改已有模型地址的协议、主机或端口时，必须为新地址重新提供密钥；原地址的已存密钥不会静默转发到另一来源。

Windows 使用系统凭据后端，macOS 使用 Keychain。若本地钥匙串不可用，设置保存会明确失败，不会改为明文保存。此时可以通过环境变量提供凭证。不要将 `.env`、加密库、运行时配置或用户研究目录提交到公开仓库。

密钥被注册到日志脱敏器，接口不会返回其明文。报告导出只从已保存的报告字段生成，不包含配置或内部运行日志。报告中的外部来源文本仍应按不可信资料处理。

搜索是可选项。未配置 Tavily 时仍使用公共资讯来源；已配置来源失败不会丢弃其他可用材料。服务自己的用量额度和费用以该服务为准。

macOS 首次读取已有密钥库时可能出现系统钥匙串授权。应用在后端启动计时前等待这一授权，同一进程复用已解锁的解密密钥，仍从磁盘读取最新密文。拒绝后不会在后台重复请求该库授权；在设置中明确保存密钥时可以重新尝试。未配置的新安装不会仅因查看配置创建解密密钥。未签名预览版更新后仍可能再次需要系统授权；正式签名和公证属于后续发行工作。
