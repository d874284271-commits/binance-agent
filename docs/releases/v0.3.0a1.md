# 0.3.0a1 开源预览候选

本文件说明 0.3.0a1 的产品变化与安装约束。可下载状态、冻结提交、系统验收记录和 SHA-256 以同版本 GitHub prerelease 为准；只有双平台原生验收和公开内容核查完成后才发布。

## 本版变化

- 一键市场研报，无需填写问题。
- 支持关联币种专题和无需币种的独立专题；独立专题不依赖 Binance 行情。
- 结论优先阅读，保留依据、风险、来源和缺口。
- 新建、更新、追问、运行中补充与恢复；历史轮次、复制和 Markdown 原生保存。
- 首次模型连接和合成示例；Tavily 搜索可选。
- 移除产品调试、评估校准与伪提醒入口，保留内部核验、风控、预算和恢复。

## 平台与安装限制

目标为 Windows x64 和 macOS Apple Silicon arm64。两平台均为未签名预览，macOS 未公证。需按系统逐应用提示核对来源；不要关闭全局安全防护。不声明 Intel Mac 或 Windows ARM 支持。

仅支持同版本 Release 中实际列明并验证过的系统范围，不把旧版候选的验收结果算作本版验收。

## 数据与升级

升级保留原有配置、会话与证据。SQLite 首次迁移前生成 `.before-reports-v1.bak` 备份，事务失败回滚；旧已完成研究仍可读。旧中断轮次若配置/版本不兼容，会明确要求重新研究。

开源许可为 MIT；第三方完整许可随包提供。用户研究、实验账本、个人工具缓存、运行时配置与未纳入本次分发的真实网页语料不进入源码候选。

## 验收记录

发布门槛包括完整 Ruff/格式/mypy/JS/pytest 检查、干净源码安装、两平台原生主流程、来源许可与数据排除检查。合成场景用于交互及故障覆盖，少量真实模型 smoke 只确认连接与执行链，不作为准确率、收益或模型优势证据。

部分网络环境中 Binance 返回 HTTP 451，市场研报会保守降级；独立专题不依赖 Binance。网页来源和模型服务也可能不可用，最终报告显示实际资料缺口。
